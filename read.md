# Week 05 JavaScript Assessment

## Project Description
This project is a console-based savings group (Ikimina) program built using JavaScript. It helps manage members' savings contributions, calculate totals, check savings status, and generate a group report.

## Objectives
- Practice JavaScript variables, data types, strings, and operators.
- Use conditions, switch statements, and loops.
- Create and test reusable functions.
- Calculate members' contributions and savings status.
- Generate a savings group report.

## Technologies Used
- HTML
- JavaScript
- Visual Studio Code
- Git and GitHub


## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Open the browser's Developer Tools and select the Console tab to view the output.

## Features
- Formats member names and phone numbers.
- Calculates monthly and yearly savings.
- Calculates total contributions for each member.
- Assigns savings status to members.
- Calculates loan limits.
- Displays a savings group report.
